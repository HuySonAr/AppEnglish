# Thuật ngữ
| Từ | Nghĩa |
|---|---|
| Unit | Nhóm các lesson; có ít nhất 5 lesson, không cố định số lượng |
| Lesson | Đơn vị học tuần tự có từ vựng, bài điền từ và test cuối |
| Lesson test | Test cuối dùng kiểm tra điều kiện hoàn thành lesson |
| Placement | Bài đầu vào cố định 23 câu, không tính progress/XP |
| Practice | Bài luyện thông thường, không cộng XP |
| Mock test | Đề thi mô phỏng, nguồn XP duy nhất |
| Attempt | Một lượt học viên làm và nộp test |
| Best score | Điểm cao nhất của học viên trên cùng đề |
| Progress | Theo dõi kết quả Reading và Listening sau placement |
